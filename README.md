# Coup d'pouce - Site Web Professionnel

Site web professionnel pour Coup d'pouce - Accompagnement scolaire pour enfants et adolescents.

## 🎨 Design Modernisé

Le nouveau design apporte les améliorations suivantes :

- **Palette de couleurs professionnelle** : Vert (#2D7A3E) comme couleur principale avec des accents roses (#E91E63)
- **Typographie moderne** : Utilisation de 'Inter' pour le corps de texte et 'Playfair Display' pour les titres
- **Layout responsive** : S'adapte parfaitement aux mobiles, tablettes et ordinateurs
- **Animations subtiles** : Effets de survol et apparition progressive des cartes de services
- **Icônes SVG personnalisées** : Icônes vectorielles nettes et professionnelles
- **Hiérarchie visuelle claire** : Structure informationnelle améliorée

## 📁 Structure du projet

```
site internet/
├── index.html      # Page principale
├── styles.css      # Feuille de style
├── script.js       # JavaScript pour les interactions
└── README.md       # Documentation
```

## 🚀 Utilisation

1. Ouvrez simplement le fichier `index.html` dans votre navigateur
2. Aucune installation ou serveur requis

## ✨ Fonctionnalités

- **Navigation fluide** : Défilement doux vers les sections
- **Formulaire de contact** : Avec validation basique
- **Section services** : Grille responsive avec 13 domaines d'intervention
- **Section À propos** : Présentation de Bénédicte Dupuis
- **Design responsive** : Optimisé pour tous les appareils

## 🎯 Sections du site

1. **Navigation** : Logo et bouton de contact
2. **Hero** : Titre principal avec illustration et boutons d'action
3. **Services** : Grille des 13 domaines d'intervention
4. **À propos** : Présentation et qualifications
5. **Contact** : Informations de contact et formulaire
6. **Footer** : Informations légales et crédits

## 📱 Compatibilité

- Chrome, Firefox, Safari, Edge (versions récentes)
- Mobile et tablette (iOS et Android)
- Écrans de bureau (toutes résolutions)

## 🔧 Personnalisation

Pour modifier les couleurs, éditez les variables CSS dans `styles.css` :

```css
:root {
    --primary: #2D7A3E;      /* Couleur principale */
    --accent: #E91E63;       /* Couleur d'accent */
    /* ... autres variables */
}
```

Pour modifier le contenu, éditez directement le fichier `index.html`.
